## 建议阅读顺序

1. 先读 `01-constants.md`：所有魔法数字的唯一出处；
2. 再读 `02-core.md` 的「数据模型」与「执行管理」：理解一次工具调用如何被校验、调度、执行；
3. 然后按兴趣读 `03`（对话回路）或 `04`（记忆与检索）；
4. `06` 是全部系统的装配现场，建议最后读。
