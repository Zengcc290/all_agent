**关键缺口（按致命程度排序）：**

1. **没有聊天 LLM 配置** —— `config/provider.toml` 不存在。`.env` 只有 embedding key，没有聊天模型 key。"得力助手"需要补一个对话模型（DeepSeek/OpenAI/本地网关均可，填 `config/provider.toml` 即可）。

**必须重写的三块（占 JS 60%）：**
1. **数据层**：现在只有 10 个硬编码节点、纯树结构、**没有 edges 数组**。知识星云的核心"跨域关联边"在数据结构中根本不存在。

**规模红线**：几十个节点体验优秀 → ~300 开始掉帧 → 2000+ 必须换 WebGL。目标定在 **200~500 节点** 恰好是 Canvas 2D 甜点区。

## 2. 目标形态：三层产品定义

```
┌─────────────────────────────────────────────────────────────┐
│  表现层：星云图 Web 前端（Aetheria 改造版）                        │
│  · 知识领域 = 恒星系团   · 主题 = 恒星   · 条目/事实 = 行星/卫星      │
│  · semantic 三元组边 = 星系间的引力桥（发光曲线）                   │
│  · 悬停看摘要 · 点击下钻详情 · 搜索定位 · 时间轴回放                 │
├─────────────────────────────────────────────────────────────┤
│  服务层：FastAPI Web API（新增，但很薄）                           │
│  · GET /api/graph    → 全图节点+边（喂给星云图）                  │
│  · POST /api/chat    → SSE 流式对话（得力助手入口）               │
│  · POST /api/ingest  → 文件上传导入（txt/md/pdf…）                │
│  · GET /api/export   → 导出 JSON/Markdown（课设硬要求）           │
├─────────────────────────────────────────────────────────────┤
│  记忆层：现有 all-agent 完全复用                                   │
│  · MemoryManager 四层记忆 + SQLite + 向量检索                     │
│  · SemanticMemory.add_fact(s,p,o) = 星云图的节点+边               │
│  · RAGPipeline = 文件导入通道                                      │
│  · ReActAgent + memory.manage 工具 = "世界最懂我的人"              │
└─────────────────────────────────────────────────────────────┘
```

**数据流闭环（这是答辩时最亮眼的故事）：**
用户输入/上传文档 → RAG 切块入库 → Agent 对话中自主调 `memory.manage`/`memory.rag` → 语义记忆沉淀三元组 → 星云图实时长出新节点/边 → 用户在星云图上看到自己的知识成长 → 点击节点可追问 Agent（图驱动的 RAG）

### 阶段 2：得力助手（3~4 天）
- 系统提示工程：身份"个人知识管家"，行为=先检索记忆再回答、自动沉淀新事实

- **自动知识抽取**：对话结束后，让 Agent 把新事实批量 `add_fact` 入库（记忆自主沉淀，星云图自动生长）
- episodic 记录每次对话 → "时间轴回放"功能（星云图按日期过滤节点）

### 防线递进（若时间不够则砍）

- **每阶段都要跑 `pytest`**（现有 26 个测试文件保你后端不退化）

## 4. 差异化亮点（答辩/报告用）

1. **"记忆共享"的具象化**：不是抽象的向量库，而是看得见的星云——AI 的新认知与你输入的知识在同一张图上共同生长。点击任何一颗星，都能看到"这是你在 2026-01-14 建立的知识，AI 在 3 天后把它与 X 关联起来"。
2. **四层认知隐喻映射**：working=会话内星尘、episodic=时间轴、semantic=恒星系结构、perceptual=图片星云。报告里这个映射本身就是创新点。
3. **GraphRAG 检索故事**：向量检索（语义相近）+ 图遍历（多跳因果）双通道，`memory.rag` 工具串起一切。
4. **工程成熟度**：63 文件 7900 行、26 个测试文件、工具自动发现协议、更新日志协议——课设里几乎没人有这个体量。
