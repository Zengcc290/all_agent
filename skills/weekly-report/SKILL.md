# 周报撰写

## 结构模板

1. **本周完成**:按优先级列出已完成事项,量化结果(完成度、数字、里程碑)。
2. **进行中**:注明当前进度与预计完成时间。
3. **风险与阻塞**:写清阻塞项、需要的支持与责任人。
4. **下周计划**:3~5 条,按优先级排序。

## 措辞规范

- 用结论开头,细节放后;一条一件事。
- 避免流水账;合并同类项,突出与目标相关的进展。
- 数字优先:能用数字就不用"很多、大幅、明显"。
